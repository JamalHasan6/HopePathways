# Hope Pathways App Assets

Place the following image files in this folder:

- **icon.png** — 1024x1024 PNG, used as the main app icon and web favicon
- **adaptive-icon.png** — 1024x1024 PNG, used as the Android adaptive icon foreground
- **splash-icon.png** — 1024x1024 PNG, used as the splash/startup screen image

## Branding guidelines

- Use calm Hope Pathways branding: green/teal colour palette
- Consider using a pathway, leaf, heart, or HP initials as the icon motif
- Avoid small text inside the app icon
- Background colour for adaptive icon and splash: `#F5FAF7`
